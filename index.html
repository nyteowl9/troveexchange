How to Get Base USDC
01
Buy USDC on Coinbase
Create a Coinbase account, complete verification, and purchase USDC. This is the fastest path — Coinbase supports Base withdrawals natively, so you skip the bridge entirely.

When withdrawing, select Base as the network. Not Ethereum. Not Polygon. Base.
02
Already Have USDC on Ethereum?
Bridge it to Base using the official Base Bridge. Takes 5–7 minutes. Small gas fee in ETH required.

Alternatively swap on Uniswap — select Base network, swap ETH → USDC directly without bridging.
03
Connect to Trove Exchange
Click "Connect Wallet" on any listing. Select your wallet from the modal. Approve the Base network connection.

You're ready to buy. USDC stays in your wallet until you purchase — we never hold your funds before an active transaction.
⚠ Important: Trove Exchange only accepts USDC on the Base network. Sending USDC on Ethereum mainnet to a Base address will result in inaccessible funds. Always double-check the network before sending. When in doubt, use Coinbase's Base withdrawal option — it handles the network selection for you.
